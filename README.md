## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Allumeria**. This trainer adds quality-of-life and progression options for Allumeria, including health protection, resource management, movement assistance, building support, and combat enhancements. It is designed around the game's exploration, crafting, voxel construction, trinket-based abilities, dungeons, and boss encounters.

**Target Audience:** Players who want to explore Allumeria's procedural world, gather resources, build freely, experiment with weapons and movement abilities, or progress through dungeons and boss battles with fewer restrictions.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Launch Allumeria first, load a save, then activate the trainer. Movement options can assist with sprinting, jumping, climbing, gliding, and flying when those abilities are available through the game's progression and equipment systems. Disable movement enhancements before entering menus or changing areas if the game behaves unexpectedly.

### Tools & Inventory

Open the inventory after loading into the world and activate item-related options only when the inventory is visible. Use these features for crafting materials, building blocks, tools, weapons, and other collected items. Save the game normally after making important changes.

### World & Environment

Use building and resource options while working on bases, underground areas, dungeons, or other discovered structures. Allumeria supports reshaping blocks, painting blocks with different palettes, and creating colored lighting, so trainer-assisted resources can help with larger creative projects.

### Combat & Weapons

Activate combat options before engaging enemies or bosses. Health protection and weapon assistance are useful for dungeon exploration and difficult encounters, while ammunition support helps maintain ranged weapons and specialized items. Turn off combat features after the encounter to keep normal progression intact.
